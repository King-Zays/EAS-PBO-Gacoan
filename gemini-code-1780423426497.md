# UI/UX REVISION GUIDELINES: MIE GACOAN SELF-ORDERING & KDS
**Target Architecture**: Java (Swing / JavaFX)
**Design Concept**: Modern Minimalism Light Mode with "Antigravity" UI (Floating elements, soft shadows, ample whitespace).

## 1. GLOBAL DESIGN SYSTEM (WAJIB DITERAPKAN)
Abaikan antarmuka terminal/gelap sebelumnya. Terapkan palet warna dan gaya berikut secara global pada seluruh komponen UI:

*   **Background App**: `#F8F9FA` (Off-White / Light Gray) - Jangan gunakan warna hitam murni atau abu-abu gelap.
*   **Background Komponen (Cards/Panels)**: `#FFFFFF` (Putih Bersih).
*   **Warna Aksen Utama**: `#EA580C` (Vibrant Orange Gacoan) untuk tombol primer dan teks *highlight*.
*   **Warna Aksen Sekunder**: `#22C55E` (Success Green) untuk indikator sukses/selesai.
*   **Teks Primer (Judul/Nama Menu)**: `#1E293B` (Dark Slate / Charcoal) - Gunakan *font weight Bold/Semi-bold*.
*   **Teks Sekunder (Catatan/Sub-judul)**: `#64748B` (Medium Gray) - Gunakan *font weight Regular*.
*   **Borders & Radius**: Hapus semua garis tepi (border) yang tajam. Gunakan `border-radius: 12px` hingga `16px` pada semua kotak, panel, dan tombol.
*   **Antigravity Effect (Shadows)**: Tambahkan efek *drop shadow* yang sangat lembut (soft, diffused shadow) di bawah semua panel/card putih agar terlihat melayang di atas *background app*.

## 2. REVISI PER HALAMAN (VIEW-SPECIFIC TASKS)

### A. Halaman System Check (Initial Screen)
*   Ubah latar belakang gelap menjadi terang (`#F8F9FA`).
*   Ubah kotak log sistem menjadi *card* melayang berwarna putih di tengah layar.
*   Ubah teks *monospaced* hijau terang menjadi teks modern yang rapi. Gunakan ikon centang hijau kecil untuk status "PASSED" dan "LOADED".
*   Ubah tombol "BUKA APLIKASI UTAMA" menjadi *rounded button* dengan warna hijau cerah yang lebih modern, beri efek bayangan lembut.

### B. Halaman Pemesanan (Kiosk Menu)
*   **Layout Menu**: Ubah kotak-kotak menu gelap menjadi daftar *Card* putih melayang (*floating cards*).
*   **Teks Menu**: Nama makanan (misal: "Mie Hompimpa") menggunakan teks warna *Dark Slate* ukuran besar. Harga diletakkan di pojok kanan *card* dengan warna hijau atau oranye.
*   **Input Field**: Ubah *text area* "Catatan Konsumen" menjadi lebih bersih (latar belakang abu-abu sangat terang `#F1F5F9`, tanpa *border* hitam tebal).
*   **Tombol**: Ubah tombol "TAMBAHKAN KAN" menjadi *rounded button* warna Oranye penuh.
*   **Keranjang Belanja (Kanan)**: Ubah latar belakang panel keranjang dari hitam menjadi putih murni dengan efek *shadow*. Teks "TOTAL TAGIHAN" diperbesar dengan warna teks utama (bukan hijau *neon*).

### C. Halaman Kitchen Display System (KDS)
*   **Konsep**: Ubah tampilan antrean menjadi gaya *Kanban Board* terang.
*   Bagian latar belakang gunakan warna *off-white*.
*   Buat dua kolom utama ("ANTREAN MASUK MASAK" dan "RIWAYAT PANGGILAN") menggunakan panel putih yang sedikit transparan atau abu-abu sangat muda.
*   Setiap pesanan yang masuk harus dirender sebagai "Kertas Order Digital" berbentuk *card* putih bersih dengan bayangan lembut.
*   Gunakan aksen garis warna di sisi kiri *card* pesanan (misal: Oranye untuk pesanan baru, Hijau untuk pesanan yang sudah dipanggil).

### D. Halaman Struk Digital (Transaksi Berhasil)
*   Hapus gaya teks seperti *Command Prompt / DOS* (teks kuning monospaced di latar hitam).
*   Buat representasi visual "Kertas Struk" sungguhan: Sebuah *card* vertikal berwarna putih bersih di tengah layar dengan bayangan sedikit lebih tebal agar terlihat *pop-up*.
*   Gunakan tipografi *Sans-Serif* modern yang diratakan tengah untuk header, dan rata kiri-kanan untuk detail pesanan. Teks menggunakan warna gelap (bukan oranye/kuning).
*   Pisahkan bagian Subtotal dan Total menggunakan garis putus-putus abu-abu halus (bukan karakter `===`).
*   Tombol "TUTUP STRUK BELANJA" menggunakan desain melengkung warna Oranye di bagian bawah struk.

## 3. INSTRUKSI EKSEKUSI UNTUK AI
*   Silakan periksa struktur kode UI saat ini.
*   Lakukan *refactoring* bertahap dimulai dari elemen UI fundamental (definisi warna, *custom buttons*, dan *panels*) sebelum mengubah struktur *layout* masing-masing halaman.
*   Pastikan integrasi *backend* (JNI Engine/Sistem Antrean) tidak terganggu oleh perubahan UI ini.
